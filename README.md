# betweenkeys.org

Static site for Between Keys, served by GitHub Pages at https://betweenkeys.org.

Learning Out Loud · Let's Grow Together

## Files
- `index.html` the home page
- `styles.css` all styling (brand: gold #C9A84C, charcoal #2C2C2C, cream #F5EFDC; Crimson Pro headings, Work Sans body)
- `404.html` not-found page
- `CNAME` tells GitHub Pages the custom domain
- `assets/` logo mark, favicons, hero and social share images

## Editing
Edit the HTML directly and commit to `main`. GitHub Pages republishes in about a minute. No build step.

## Rules for copy
- No em dashes. Commas for asides, periods for breaks.
- First person, peer voice. Learning, not lecturing.
- No Rollings Home Team or eXp references.
